# Programming Basics

Tijdens deze cursus leer je de basisprincipes van programmeren. We gebruiken daarvoor de Circuit Playground Express,
een development bord dat programmeerbaar is in JavaScript.

## Inhoud

In deze repository vind je de uitwerkingen van de lesopdrachten en zelfstudie opdrachten.

Kopieer de code naar [MakeCode Adafruit](https://makecode.adafruit.com) om deze uit te voeren of te downloaden naar de
CPX.

**De lesopdrachten en theorie van de cursus staan op Brightspace.**
